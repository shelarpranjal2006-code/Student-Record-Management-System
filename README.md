# Student-Record-Management-System
Student Record Management System using Python and Excel
Student Record Management System

1. Project Overview

The Student Record Management System is a Python-based project used to manage student information digitally. It allows users to add, view, and delete student records easily.

2. Project Objective

The main objective of this project is to store and manage student information in an Excel file. It reduces manual work and makes student record management simple and efficient.

3. Technologies Used

- Python
- Visual Studio Code (VS Code)
- OpenPyXL Library
- Microsoft Excel

4. Project Features

1. Add New Student

- Accepts student name, contact number, class, and address.
- Saves student details into an Excel file.
- Displays a success message after saving.

2. View Students

- Displays all student records in the terminal.

3. Delete Student

- Accepts the student's contact number.
- Deletes the matching student record from the Excel file.
- Displays a success message after deletion.

4. Exit

- Closes the program.

5. Installation

Install Python on your computer.

Install the required library using:

pip install openpyxl

6. How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python student.py
